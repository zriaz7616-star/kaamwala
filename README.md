# KaamWala

Free invoice generator for Pakistani freelancers, shops, and small businesses.

## Features

- Business profile (name, logo, license, contact) — auto-filled on every invoice
- Product/service list with rates — pick from dropdown while invoicing
- JazzCash, Easypaisa, Bank payment details + QR code
- Professional PDF export with letterhead
- Share via WhatsApp, Email, or any app
- Invoice history with edit & delete
- 100% offline after first load
- No signup, no tracking, no ads — data stays on your phone

## Tech

Pure HTML, CSS, and JavaScript. Hosted free on GitHub Pages.
